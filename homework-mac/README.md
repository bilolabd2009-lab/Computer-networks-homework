# Домашнее задание: MAC-адресация, коммутатор, дуплекс

## 1. Таблица MAC-адресов устройств

| Устройство | Интерфейс | MAC-адрес |
|---|---|---|
| PC1 | Ethernet | 00:1A:2B:3C:4D:01 |
| PC2 | Ethernet | 00:1A:2B:3C:4D:02 |
| PC3 | Ethernet | 00:1A:2B:3C:5D:03 |
| SW1 | VLAN1 (управление) | 00:1A:2B:3C:5E:01 |

## 2. Схема соединения компьютеров с коммутатором

Коммутатор SW1 с портами Fa0/1, Fa0/2, Fa0/3.
К портам подключены PC1, PC2, PC3 соответственно.

- PC1 — MAC: 00:1A:2B:3C:4D:01 — Fa0/1
- PC2 — MAC: 00:1A:2B:3C:4D:02 — Fa0/2
- PC3 — MAC: 00:1A:2B:3C:4D:03 — Fa0/3

## 3. Таблица MAC-адресов коммутатора

| № | MAC-адрес | Порт коммутатора |
|---|---|---|
| 1 | 00:1A:2B:3C:4D:01 | Fa0/1 |
| 2 | 00:1A:2B:3C:4D:02 | Fa0/2 |
| 3 | 00:1A:2B:3C:4D:03 | Fa0/3 |

## Принцип работы коммутатора

- Коммутатор запоминает MAC-адрес источника и порт, с которого пришёл кадр.
- При отправке на известный MAC-адрес кадр направляется только в нужный порт.
- Если MAC-адрес назначения неизвестен, кадр рассылается на все порты (кроме входящего).

## 4. Возможная ошибка и её исправление

**Ситуация:** Порт коммутатора Fa0/1 настроен в полнодуплексном режиме, а компьютер PC1 работает в полудуплексном режиме.

**Последствия:**
- Возникают коллизии и ошибки CRC.
- Сеть работает медленно.
- В консоли коммутатора появляется сообщение: %CDP-4-DUPLEX_MISMATCH: duplex mismatch discovered on FastEthernet0/1

**Способы исправления:**

1. Ручная настройка.
   - На коммутаторе: interface fa0/1 -> duplex full -> speed 100
   - На ПК: в свойствах сетевой карты установить "100 Мбит/с, полный дуплекс".

2. Включение автоопределения.
   - На коммутаторе: interface fa0/1 -> duplex auto -> speed auto
   - На ПК: включить автоопределение в драйвере сетевой карты.
