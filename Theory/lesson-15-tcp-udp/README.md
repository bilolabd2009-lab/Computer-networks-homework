# Урок 15. TCP и UDP: надежность, порядок и цена соединения

## 1. Место транспортного уровня

Транспортный уровень находится между прикладным и сетевым уровнями стека TCP/IP.
Его задача — обеспечить связь не между компьютерами, а между приложениями (процессами)
на этих компьютерах.

Для адресации используется порт — число от 1 до 65535. Комбинация IP-адреса и порта
называется сокетом.

## 2. UDP — быстро, но без гарантий

UDP (User Datagram Protocol) — дейтаграммный протокол:
- нет установления соединения;
- нет подтверждений и повторной отправки;
- нет гарантии порядка и доставки;
- нет управления потоком и перегрузкой.

Заголовок UDP — всего 8 байт.

Когда это оправдано:
- короткие запросы-ответы (DNS, DHCP);
- службы, где потеря пакета не критична (TFTP, SNMP);
- потоковое видео, IP-телефония, игры.

## 3. TCP — надёжно, но дороже

TCP (Transmission Control Protocol) — протокол с установлением соединения,
обеспечивающий надёжную передачу потока байт.

Гарантии TCP:
- доставка данных;
- сохранение порядка следования;
- защита от дублирования и потерь;
- управление потоком и перегрузкой.

## 4. Установка и завершение соединения

Трёхкратное рукопожатие (3-way handshake):
1. A -> B: SYN (SEQ = x)
2. B -> A: SYN + ACK (SEQ = y, ACK = x+1)
3. A -> B: ACK (SEQ = x+1, ACK = y+1)

Завершение — обмен сегментами с флагом FIN и подтверждениями ACK.

## 5. Сравнение TCP и UDP

| Критерий | TCP | UDP |
|---|---|---|
| Соединение | Устанавливается | Нет |
| Надёжность | Гарантирована | Нет |
| Порядок | Сохраняется | Не гарантируется |
| Подтверждения | Да | Нет |
| Повторная отправка | Да | Нет |
| Управление потоком | Да | Нет |
| Скорость | Ниже | Выше |
| Заголовок | 20–60 байт | 8 байт |
| Примеры | HTTP, FTP, SMTP | DNS, DHCP, TFTP, VoIP |

## 6. Итоговая формула

TCP = надёжность + порядок + управление потоком и перегрузкой - скорость - простота.
UDP = скорость + простота - надёжность - порядок.
